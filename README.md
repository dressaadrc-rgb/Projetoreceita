# 🍴 Projeto Receita

Um projeto desenvolvido para praticar e aprimorar conhecimentos em desenvolvimento web, criando uma página de receitas com uma interface simples, organizada e intuitiva.

## 🌐 Acesse o projeto

👉 [Visualizar o site](https://dressaadrc-rgb.github.io/Projetoreceita/)

## 📋 Sobre o projeto

O **Projeto Receita** foi desenvolvido como um exercício prático de desenvolvimento web, com o objetivo de colocar em prática conceitos de estruturação de páginas, estilização e organização de conteúdo.

A página apresenta uma proposta simples e visual para exibição de receitas, buscando proporcionar uma experiência agradável e fácil de navegar.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Git
* GitHub
* GitHub Pages

## 🎯 Objetivos de aprendizagem

Durante o desenvolvimento deste projeto, foram praticados conceitos como:

* Estruturação de páginas com HTML;
* Estilização utilizando CSS;
* Organização de elementos e conteúdos;
* Desenvolvimento de interfaces para web;
* Versionamento de código com Git;
* Publicação de projetos utilizando GitHub Pages.
